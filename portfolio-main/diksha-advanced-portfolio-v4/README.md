# Diksha Koppad — Advanced Portfolio

A modern, responsive, GitHub Pages-friendly portfolio built with **HTML, CSS and JavaScript**.

## Included
- Animated hero with typing roles
- Dark/light theme toggle
- Responsive mobile navigation
- Scroll progress bar + active section navigation
- Scroll reveal animations
- Interactive project filters
- Project detail modal
- Live GitHub repository loading using the public GitHub API
- Experience timeline
- Skills dashboard
- Education + certificate links
- Resume link
- Responsive layout for mobile, tablet and desktop

## Run locally
Open `index.html` directly, or use VS Code **Live Server**.

## Deploy to GitHub Pages
1. Push the contents of this folder to your portfolio repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select `main` and `/root`.
5. Save and wait for GitHub Pages to publish.

## Assets
Your supplied portfolio assets were retained where useful. `assets/profile.jpg` is a cropped copy of the supplied profile photo. `assets/resume.pdf` is copied from the uploaded portfolio repository.

## Easy edits
- Main content: `index.html`
- Colors/layout: `style.css`
- Animations/interactions/GitHub API: `script.js`
- Profile image: `assets/profile.jpg`
- Resume: `assets/resume.pdf`
