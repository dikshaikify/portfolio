# Diksha Koppad — Advanced Portfolio

Static GitHub Pages portfolio built with HTML, CSS and JavaScript.

## Highlights
- Premium animated glassmorphism UI with colorful aurora background
- Responsive navigation, dark/light theme and scroll progress
- Project filters and project detail modals
- Live GitHub public repository cards
- Coding dashboard links
- Education, experience and skills sections
- MySQL certificate has a visible image preview plus an in-page PDF viewer
- Resume and certificate assets are stored locally for GitHub Pages

## Run locally
Open `index.html` with Live Server in VS Code, or deploy the folder to GitHub Pages.
